# IAmecc - Automotive Diagnostic & Procurement Suite
App mobile di fascia altissima per diagnosi acustica tramite AI, cataloghi ricambi, preventivi dinamici e ordinazione automatica B2B.

## Struttura del Progetto
- `/frontend`: Interfaccia utente mobile (Flutter / React Native).
- `/backend`: API server-side per gestione listini, preventivi e PDF.
- `/ai_model`: Modelli di Machine Learning per l'analisi acustica in Edge Computing.
